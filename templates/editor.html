新建模板：使用外部 AI 解析规则文档

  1. 点「复制提示词」。
  2. 打开任意一个外部网络 AI 网站，把提示词和规范一起发给它。规范是文件就上传文件，是纸质件就拍照。
  3. 把 AI 回复的内容整段粘到下面输入框，点「解析」。
  4. 核对一遍，点最下面的「保存为新模板」，填个名称。不保存不会留下来。

注意⚠️：未公开材料、学生材料、含个人信息的文件不要发给外部 AI；AI 整理的规则必须逐条对照正式文件核对。

你是格式规范整理助手。下面我会给你一份文档格式规范（Word 文档、PDF、截图或文字都可能有）。请把它整理成机器能读的规则清单。 只输出一个 JSON 数组，不要解释，不要 Markdown 代码块。数组里每一项是一条格式要求： { "section": "下方清单里的英文标识，必填", "label": "中文名称，必填", "font": "字体，如 宋体、黑体、楷体、仿宋、Times New Roman、Arial Black", "size_pt": 字号磅值，数字，如 16、15、12、10.5、9, "size_name": "中文字号，如 三号、小三、小四、五号、小五", "bold": true 或 false, "alignment": "居中" 或 "两端对齐" 或 "左对齐", "line_spacing_pt": 固定行距磅值，数字，如 22、18, "line_spacing_type": "固定值" 或 "多倍行距" } 规范里没写的字段一律不填，不要按常识补。 size_pt 与 size_name 必须对应： 初号42 小初36 一号26 小一24 二号22 小二18 三号16 小三15 四号14 小四12 五号10.5 小五9 六号7.5 小六6.5 section 只能从下面这些里选： cover_title 封面题目 cover_field 封面上的姓名、学号、专业、指导教师、日期 abstract_zh_title 中文摘要标题 abstract_zh_body 中文摘要正文 keywords_zh 中文关键词 abstract_en_title 英文摘要标题 Abstract abstract_en_body 英文摘要正文 keywords_en 英文关键词 Key words toc_title 目录标题 level1_title 一级标题 level2_title 二级标题 level3_title 三级标题 body_text 正文 figure_caption 图题注 table_caption 表题注 footnote 脚注 reference_title 参考文献标题 reference_entry 参考文献条目 page_number 页码 page_header 页眉 下面这几类用专门字段，不要写成普通字体规则： 参考文献最少篇数：{"section":"reference_count","label":"参考文献数量","min_count":20} 外文文献最少篇数：{"section":"reference_foreign_count","label":"外文文献数量","min_count":3} 正文字数：{"section":"word_count","label":"正文字数","min_words_design":7000,"min_words_paper":10000} 摘要字数：{"section":"abstract_word_count","label":"摘要字数","min_words":400} 页面设置：{"section":"page_setup","label":"页面设置","paper":"A4","width_mm":210,"height_mm":297} 页眉：{"section":"page_header","label":"页眉","font":"宋体","size_pt":9,"size_name":"小五","header_text":"页眉上要出现的文字"} 要求： 1. 只提取规范里明确写出来的要求，没写的不补。 2. 同一项在规范里出现多次时，以正文部分的要求为准，目录里的写法不算。 3. 一个对象只出一条规则，同一对象的多条要求合并。 4. 页眉文字照抄原文，不要改写。 5. 必须是合法 JSON，引号用英文半角。
