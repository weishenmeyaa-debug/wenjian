# 毕业设计格式检测工具

上传 Word 论文，自动检测格式是否符合规范，生成可下载的检查报告。

## 功能

- 字体字号检测（封面、标题、正文、摘要、参考文献等）
- 段落对齐、行间距检测
- 图表编号格式检测（含子编号）
- 脚注编号与格式检测
- 参考文献数量与格式检测（GB/T 7714）
- 页眉、页面设置检测
- 规则编辑器：自定义格式规范，适配不同学校
- AI 批量导入规则
- 格式参考页面：正确格式示例

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 启动
python app.py

# 打开浏览器访问
http://localhost:5001
```

Windows 用户也可以双击 `start.bat`，Mac 用户双击 `start.command`。

## 自定义规则

内置规则为默认格式规范。如果你们学校的要求不同：

1. 打开「规则编辑器」页面
2. 编辑或通过 AI 批量导入规则
3. 保存为新规范，立即生效

详细说明见 [使用指南](使用指南.md)，也可以看 [小红书使用教程](http://xhslink.com/o/YPxpXsGCBh)。

## 技术栈

- Python 3 + Flask
- python-docx（文档解析）
- HTML + CSS + JS（前端）
