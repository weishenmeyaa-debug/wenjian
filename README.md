# 格式检查器 · Word 文档格式检查

一个在本机运行的 Word 文档格式辅助检查工具。选择规则模板、添加文档，即可得到按轻重分类的问题清单。

> 格式检查器只检查格式，不生成、改写或代写文档内容；检查结果需要人工复核。

## 能做什么

- 检查字体、字号、段落、标题编号、图表编号、页面设置等可读取格式
- 按不同材料切换模板，指定其中一个为主模板
- 一次检查多个 Word 文档（最多 12 个，合计不超过 96MB）
- 在浏览器中查看结果并下载临时 HTML 报告
- 在「模板规则」页切换、逐条编辑、改名并把改动存成新模板

模板不是写死的。新建模板时把格式规范交给任意一个外部 AI，让它按页面上的提示词整理成规则，再把结果贴回来保存。工具本身不读规范文件，也不联网。

当前最可靠的输入是 `.docx`。旧 `.doc` 仅在 macOS 且系统具备转换能力时兼容；其他系统请先在 Word 或 WPS 中另存为 `.docx`。

## 本地运行

需要 Python 3.9 或更高版本。

### macOS

双击 `start.command`。如果系统阻止首次运行，右键该文件并选择“打开”。

### Windows

双击 `start.bat`。

也可以在终端手动运行：

```bash
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py --port 5001
```

然后访问 [http://127.0.0.1:5001](http://127.0.0.1:5001)。服务只监听本机地址。

## 使用流程

1. 选择这份材料应该遵守的模板。
2. 添加一个或多个 `.docx` 文件。
3. 开始检查，按“必须修改、建议复核、人工确认”处理结果。
4. 回到 Word 修改原文件；格式检查器不会直接改动上传的文件。

随项目带的是一套「示例模板」，只用来演示整个流程。查自己的材料之前，先用自己的规范建一套模板——不同材料（毕业论文、课程作业、项目申报书、公文等）的要求差别很大，套别人的模板会误判。

详细说明见 [使用说明](使用说明.md)（同内容的 [PDF 版](使用说明.pdf) 适合直接发给用的人），维护细节见 [使用指南](使用指南.md)，也可以看 [小红书使用教程](http://xhslink.com/o/YPxpXsGCBh)。

## 隐私与安全

- 文档仅在本机处理，不发送到外部服务。
- 上传副本在本次检查结束后清理。
- 下载报告只在当前程序运行期间短期保留在内存中。
- 不需要 API Key、Token 或外部账号。
- 整理规则时规范文件是发给外部 AI 的，本工具不经手，也不联网。未公开的规范、学生材料、含个人信息的文件不要发给外部 AI。
- 不要把学生材料、未公开文件或真实检查报告提交到公开仓库。

即使在本机，也建议用脱敏副本检查包含姓名、学号或其他个人信息的文档。

## 项目结构

- `app.py`：本地 Web 应用与文件生命周期
- `checker.py`：规则执行与问题定位
- `report.py`：可下载报告
- `format_rules.json`：内置示例模板
- `specs/`：自己保存的模板
- `settings.json`：记录哪套是主模板（本机设置，不进版本库）
- `templates/`、`static/`：页面与视觉样式
- `tests/`：自动测试

## 重要限制

Word 的继承样式、复杂域、浮动对象、分节与最终分页并不总能被 `python-docx` 完整还原。格式检查器应被视为“先找出一批明确问题”的工具，而不是合规证明。
