# 文检 · Word 文档格式检查

一个在本机运行的 Word 文档格式辅助检查工具。选择规则模板、添加文档，即可得到按轻重分类的问题清单。

> 文检只检查格式，不生成、改写或代写文档内容；检查结果需要人工复核。

## 能做什么

- 检查字体、字号、段落、标题编号、图表编号、页面设置等可读取格式
- 按不同材料切换规则模板
- 批量检查多个 Word 文档
- 在浏览器中查看结果并下载临时 HTML 报告
- 在规则库中查看、调整并另存本地规则

当前最可靠的输入是 `.docx`。旧 `.doc` 仅在 macOS 且系统具备转换能力时兼容；其他系统请先在 Word 或 WPS 中另存为 `.docx`。

## 本地运行

需要 Python 3.10 或更高版本。

### macOS

双击 `start.command`。如果系统阻止首次运行，右键该文件并选择“打开”。

### Windows

双击 `start.bat`。

也可以在终端手动运行：

```bash
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py --port 5001
```

然后访问 [http://127.0.0.1:5001](http://127.0.0.1:5001)。服务只监听本机地址。

## 使用流程

1. 选择这份材料应该遵守的规则模板。
2. 添加一个或多个 `.docx` 文件。
3. 开始检查，按“必须修改、建议复核、人工确认”处理结果。
4. 回到 Word 修改原文件；文检不会直接改动上传的文件。

“本科毕业设计（论文）”是随项目提供的一套示例规则，不是产品名称。不同学校、课程或材料应建立自己的规则模板，并对照正式规范核验。

详细说明见 [使用指南](使用指南.md)，也可以看 [小红书使用教程](http://xhslink.com/o/YPxpXsGCBh)。

## 隐私与安全

- 文档仅在本机处理，不发送到外部服务。
- 上传副本在本次检查结束后清理。
- 下载报告只在当前程序运行期间短期保留在内存中。
- 不需要 API Key、Token 或外部账号。
- 不要把学生材料、未公开文件或真实检查报告提交到公开仓库。

即使在本机，也建议用脱敏副本检查包含姓名、学号或其他个人信息的文档。

## 项目结构

- `app.py`：本地 Web 应用与文件生命周期
- `checker.py`：规则执行与问题定位
- `spec_parser.py`：从规范文档有限提取规则草稿
- `report.py`：可下载报告
- `format_rules.json`：内置示例规则
- `specs/`：本地规则模板
- `templates/`、`static/`：页面与视觉样式
- `tests/`：自动测试

## 重要限制

Word 的继承样式、复杂域、浮动对象、分节与最终分页并不总能被 `python-docx` 完整还原。文检应被视为“先找出一批明确问题”的工具，而不是合规证明。
