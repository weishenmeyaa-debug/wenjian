格式检查器 · 使用说明

在自己电脑上跑的 Word 文档格式检查工具

选好模板、把文档放进去，它按模板逐项比对，列出不符合的地方。改还是你自己回 Word 改。

它只查格式：字体、字号、行距、段落、标题编号、图表编号、页面设置这些能从文件里读出来的东西。文字写得好不好、论证是否成立、版面好不好看，它不管，也不给分。

一、用之前

项目要求
电脑Windows 10 以上，或 macOS
Python3.9 或更高。没装过的现装一个，Windows 安装时勾上 Add python.exe to PATH
网络只有第一次启动需要联网下载依赖，之后全程离线

Python 下载：python.org/downloads。国内打不开时用镜像站（华为云、清华 TUNA 都有安装包）。Mac 装完还要打开「应用程序 → Python 3.x」文件夹，双击运行一次 Install Certificates.command，否则下面装依赖会报证书错误，看起来像断网。

二、第一次打开

  1. 把整个文件夹解压到一个固定位置，比如「文档」目录下面。不要放在 U 盘里，也不要放到 OneDrive、iCloud、坚果云这类同步目录里——程序自带的环境有几万个小文件，同步会卡死。
  2. Mac 双击 start.command；Windows 双击 start.bat。Mac 第一次可能提示「无法打开，因为无法验证开发者」，右键点它 → 打开。
  3. 窗口里会打印一行地址，浏览器通常自动打开。第一次要装依赖，等一分钟左右。
  4. 这个窗口别关，关了程序就停了。用完再关。

三、检查一篇文档

  1. 首页选模板。列表里带 ★ 的是主模板，打开时默认选它。
  2. 把 .docx 拖进页面，或点选文件。一次最多 12 个，合计不超过 96MB。
  3. 点「检查所选文档」。
  4. 结果分三类：必须修改、建议复核、需要人工确认。先处理必须修改的。
  5. 回 Word 改原件。工具不会改动你的文件。
  6. 需要留档就下载报告。报告只在程序运行期间保留，关掉就没了。

四、模板要自己建

随包带的「示例模板」只是为了让你看到流程长什么样。拿它去查自己的材料会误判——每所学校、每份材料的要求都不一样。

新建模板不用一条条手输：

  1. 进入「模板规则」，点「复制提示词」。
  2. 打开任意一个联网的 AI 网站，把提示词和你那份格式规范一起发给它。规范是电子文件就上传，是纸质的就拍照。
  3. 把它回的内容整段复制，粘回页面，点「解析」。
  4. 逐条核对。AI 会看错、会漏、也会编，对着正式文件核一遍再存。
  5. 点「保存为新模板」，起个能认出来的名字，比如「××学院毕业论文」。
  6. 以后在模板列表里把它设为主模板。
⚠️ 未公开的规范、学生材料、含姓名学号的文件，不要发给外部 AI。

五、四件要说清楚的事

  • 一次最多 12 个文件、合计 96MB。
  • 旧的 .doc 只能救急：Mac 会自动转换，Windows 请先在 Word 或 WPS 里「另存为」.docx。
  • 它不代写、不改你的文件、也不替代正式规范。最终以学校、期刊、单位发布的正式文件为准。
  • 结果要人看。Word 的样式继承、域、浮动对象，程序读不全，这类会标成「需要人工确认」，不是漏了。

六、隐私

  • 文档只在你自己的电脑上处理，不上传、不联网、不需要账号。
  • 上传的副本在检查结束后删除。
  • 检查报告只在程序运行期间留在内存里，关掉就没了。

七、常见问题

双击没反应，或窗口一闪就没了

Mac：右键 → 打开。Windows：右键 →「以管理员身份运行」一次，或看清窗口最后一行报什么错。

提示「未找到 Python」

没装，或者没加进 PATH。Windows 重装时勾上 Add python.exe to PATH；Mac 也可以在终端输入 xcode-select --install 装命令行工具。

第一次启动卡在「正在安装依赖」

多是网络。Mac 先运行 Install Certificates.command，再重新双击。还不行就换个网络（手机热点）。

浏览器没有自动打开

看窗口里那行地址，一般是 http://localhost:5001，手动粘到浏览器。端口被占用时程序会自动换一个，以窗口显示的为准。

结果和肉眼看到的不一样

先确认选对了模板，再到 Word 的「样式」面板核对那一段。程序读不出来的项目以人工判断为准。

怎么停下来

关掉那个黑色窗口。Mac 上是「终端」窗口。

换电脑、更新程序

程序文件可以整个覆盖。specs/ 文件夹是你自己存的模板，settings.json 记着哪套是主模板，这两样留着别删。
